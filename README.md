# Microsoft MB-910: Dynamics 365 Fundamentals (CRM) Study Guide

## Introduction

This repository is an independent study guide for **Microsoft MB-910: Dynamics 365 Fundamentals (CRM)**.

IMPORTANT: **MB-910 was retired on December 31, 2025 and can no longer be taken.** Microsoft has also deprecated the Dynamics 365 Fundamentals (CRM) certification. This repository is therefore useful as a historical MB-910 study reference and as foundational learning material for Dynamics 365 CRM concepts.

Microsoft's current Dynamics 365 credential guidance states that the Dynamics 365 Fundamentals certifications are deprecated, while previously earned certifications remain on the holder's transcript.

## Detailed Study Notes

### CRM

Customer Relationship Management systems help organizations manage interactions with customers and prospects.

A CRM can connect:

**Customer → Account → Contact → Lead → Opportunity → Sale → Service**

### Dynamics 365 Customer Insights

Customer Insights helps organizations understand customers using unified data and customer-related insights.

Important concepts:

- Customer profiles
- Segments
- Customer data
- Journeys
- Personalization
- Customer engagement
